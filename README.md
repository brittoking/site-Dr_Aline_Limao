# Dra. Aline Limão — Estética Avançada

Landing page responsiva para **Dra. Aline Limão - Estética Avançada**, em Bauru/SP.

## Destaques

- Layout moderno e responsivo
- Fotos profissionais integradas ao design
- Botões diretos para WhatsApp
- Seções de apresentação, tratamentos, avaliações e contato
- Link para Instagram e Google Maps
- Menu mobile
- Animações suaves ao rolar a página

## Estrutura

```text
site-aline-limao/
├── assets/
│   ├── aline-hero.jpg
│   └── aline-clinica.jpg
├── index.html
├── style.css
├── script.js
└── README.md
```

## Como executar

Abra o arquivo `index.html` no navegador ou publique o projeto em GitHub Pages, Netlify ou Vercel.
